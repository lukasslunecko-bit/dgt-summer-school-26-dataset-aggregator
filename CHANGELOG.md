# Changelog

## 0.2.1

- Add a desktop multi-folder browser with native Ctrl+click and Shift+click range selection.
- Retain single-folder navigation and an explicit option to add the currently displayed folder.

## 0.2.0

- Rename the automatic-correction backup folder to `5-automated backups` while continuing to exclude legacy backup folders from scans.
- Add cross-project text and CSV reports with project totals, aggregate segment counts, paired/orphaned file counts, and attention items.
- Add the project-relative original filename as the first aggregate column by default, with an option to disable it.
- Add multi-select individual CSV/TSV input in the desktop interface and repeatable `--input-file` CLI arguments.
- Preserve previous cached project inputs during incremental individual-file runs.

## 0.1.0

- Initial public release.
